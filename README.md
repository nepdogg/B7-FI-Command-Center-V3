# B7 FI Command Center V5.4.4

## Live Operations Proportion + Shell Alignment

This build continues from V5.4.3 and preserves the existing `b7fi-command-center-v3` localStorage data.

### Changes in V5.4.4
- Rebalanced the six-panel Live Tool Card so the top row is substantially taller and the bottom row is shorter.
- Increased both Live Operations rotating frames together to 632px so Status Carousel and Tool Carousel remain identical dimensions.
- Added breathing room to Ship/FI/Cycle Time and the six progress bars without adding internal scrollbars.
- Tightened the lower Tool Information, Active FI Checklists, and Next Lead/Admin panels to use their reduced height efficiently.
- Standardized the normal site shell to a shared 6px browser-edge gutter. Header, main navigation, alert/status bars, page navigation, body, and footer now share the same left/right edges.
- Screenshot and Presentation modes retain their special full-report/fullscreen behavior.
