FI COMMAND CENTER V14.0.83

Hybrid Presentation centers and enlarges both quarter headings. The dark
countdown insets extend to the thin lower trim. Up to two translucent
tool previews appear on either side of the selected card. Use Previous,
Next, or the arrow keys to move through the tools.

LOCAL
Extract to a new folder. Close the previous server and run
START-COMMAND-CENTER.bat from the new folder.

GITHUB PAGES
Replace index.html, css/command-center.css and js/command-center.js together.
Keep existing assets and confirm V14.0.83 after reloading.
